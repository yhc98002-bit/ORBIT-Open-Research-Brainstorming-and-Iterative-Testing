# Concurrent Work Watchlist

This is the canonical ORBIT watchlist for related work from the last 3 months.

Concurrent work is not an automatic proposal rewrite trigger. It should be classified,
positioned, and revisited when needed. Reopen `FINAL_PROPOSAL.md` only when
`/novelty-check` classifies the work as `STRONG_BLOCKER` or a human explicitly asks for a
proposal revision.

## Policy

- Default window: last 3 months.
- Default action: watchlist entry plus related-work or positioning note.
- Proposal rewrite trigger: `STRONG_BLOCKER` only, or explicit human decision.
- Non-blocking classes:
  `RELATED_BUT_DIFFERENT`, `CONCURRENT_WORK`, `WEAK_BLOCKER`,
  `POSITIONING_TARGET`, `REPRODUCTION_TARGET`.
